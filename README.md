
# HR Workforce Intelligence System

## Overview

An HR workforce analysis project using SQL Server to analyze employee, department, and performance data and derive workforce insights.

## Business Problem

Analyze workforce data to understand salary distribution, employee performance, department-level trends, bonus information, and performance review status.

## Tools & Technologies

- SQL Server
- SQL

## SQL Concepts Used

- Filtering and Aggregation
- GROUP BY and HAVING
- CASE Statements
- Subqueries
- CTEs
- Window Functions
- LEFT JOIN
- Self Join
- Correlated Subqueries

## Key Insights

- Analyzed salary distribution across 4 departments
- Identified employees with performance Rating 5
- Calculated department-wise bonus totals
- Identified employees with no performance reviews
- Mapped manager–employee hierarchies using Self Join
- Compared individual salaries against department averages using correlated subqueries
